# Nailtopia website

A web-based booking and management platform for a nail salon,
automating client appointment scheduling and reminders, enabling upfront payments, and
improving appointment tracking for the owner.

Live Demo:
https://nail-website-lqsp.onrender.com

Architecture:
next-auth/OAuth2 authentication → NEXT.js frontend → Stripe → NEXT.js backend → Convex

Features

- Calendars
- Appointment booking
- Online payments
- Email reminders
- Smooth user interface for viewing the catalog of services & prices
- Authentication

Tech Stack

- Next.js
- Convex
- Tailwind
- Google OAuth2
- Stripe
- nodemailer
